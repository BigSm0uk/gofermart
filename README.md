# Gophermart — Накопительная система лояльности

Данный проект выполнен в рамках курса **«Продвинутый Go-разработчик»** от Яндекс Практикума.

## О проекте

**Gophermart** — это сервис накопительной системы лояльности. Он позволяет пользователям регистрироваться, передавать номера заказов и получать за них вознаграждение (баллы), которые затем можно использовать для оплаты новых заказов.

### Ключевые возможности:
- Регистрация и аутентификация пользователей.
- Прием и проверка номеров заказов (алгоритм Луна).
- Взаимодействие с внешней системой расчета начислений.
- Учет баланса и истории списаний баллов.

## Использование Makefile

В проекте используется `Makefile` для автоматизации рутинных задач.

| Команда | Описание |
| :--- | :--- |
| `make help` | Показать список доступных команд |
| `make deps` | Загрузить и проверить зависимости Go |
| `make run-gof` | Запустить основной сервис (Gophermart) |
| `make run-acc` | Собрать и запустить сервис начислений (Accrual) |
| `make test` | Запустить модульные тесты с проверкой покрытия |
| `make integration-test` | Запустить интеграционные тесты |
| `make format` | Отформатировать код с помощью `go fmt` |
| `make linter-golangci` | Запустить линтер `golangci-lint` |
| `make swag-v1` | Сгенерировать Swagger-документацию |
| `make pre-commit` | Выполнить все проверки перед коммитом (линтеры, тесты, генерация доков) |

## Быстрый старт

1. Склонируйте репозиторий.
2. Настройте переменные окружения в файле `.env` (используйте `.env.example` как образец).
3. Установите зависимости:
   ```bash
   make deps
   ```
4. Запустите сервис:
   ```bash
   make run-gof
   ```
